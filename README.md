# Jira Apps — Community

Questions, feature requests and discussion for the Jira Cloud apps published by
**Two Little Moons Consulting** on the Atlassian Marketplace.

Head to **[Discussions](https://github.com/ethanj2k/jira-apps-community/discussions)**
to ask anything. No account beyond a free GitHub login is needed, and every thread is
public so the next person with the same question finds the answer.

## What to post where

| You want to | Go to |
|---|---|
| Ask how something works, or whether an app can do X | [Discussions → Q&A](https://github.com/ethanj2k/jira-apps-community/discussions) |
| Suggest a feature, or vote on one | [Discussions → Ideas](https://github.com/ethanj2k/jira-apps-community/discussions) |
| Report a bug | [Issues](https://github.com/ethanj2k/jira-apps-community/issues) |
| Raise something private (billing, licensing, your data) | [Support](https://ethanj2k.github.io/support.html) |

Please do not paste credentials, API tokens or customer data into a public thread.

## House rules

Be civil, stay on topic, and search before you post. Threads that are abusive or
off-topic get locked.
